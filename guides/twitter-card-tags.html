Twitter Cards: How to Make Your Links Stand Out on X

A plain link on X is easy to scroll past. A Twitter Card turns that link into a rich preview: a large image, a title, and a description that take up real space in the timeline. Cards can double the clicks a link earns, and they cost nothing but a few tags in the head of the page.

This guide explains the card types, the tags each one needs, the image rules, and how to test your cards before posting.

The two main card types

The summary card shows a small square thumbnail beside the title and description. It suits news, blog posts, and pages where the image is secondary. The summary_large_image card shows a wide image above the title and description, and it suits visual content: products, recipes, photography, and landing pages.

Choose the card per page, not per site. A photo-heavy page deserves the large card; a text-heavy article can use the summary card. The tag twitter:card sets the type, and the value is either 'summary' or 'summary_large_image'.

The tags a Twitter Card needs

The minimum set is twitter:card, twitter:title, and twitter:description, plus twitter:image for the large card. If you already have Open Graph tags, X will fall back to them for missing values, so a page with good Open Graph tags often shows a decent card with no Twitter-specific tags at all.

For best results, set the Twitter tags explicitly rather than relying on the fallback. Add twitter:site with your handle so the card links to your account, and twitter:creator with the author's handle for articles. Explicit tags remove ambiguity and make testing easier.

Image rules for Twitter Cards

The large card image should be at least 300 by 157 pixels, with 1200 by 628 recommended for sharp display. The summary card image should be at least 144 by 144 pixels, square. Use JPG, PNG, or GIF, keep the file under 5 MB, and use an absolute URL.

Keep important text and faces away from the edges, because X crops images differently on phones and desktops. Test the card on both. And remember that the image is the first thing people see: a clear, high-contrast image with one subject outperforms a busy collage.

Testing your Twitter Card

X has a Card Validator that shows exactly how your card will look and reports missing or invalid tags. Paste your page URL, check the preview, fix any problems, and re-validate. X caches cards, so changes may take time to appear in the timeline after the first share.

If a card does not appear at all, check the common causes: the page has no twitter:card tag and no Open Graph fallback, the image URL is relative or blocked, or the image is too small. Fix the cause, re-validate, and post again.

Key takeaways

  • Use summary_large_image for visual pages and summary for text-heavy pages.
  • Set twitter:card, title, description, and image explicitly; do not rely only on the Open Graph fallback.
  • Use a 1200 by 628 pixel image for large cards, with an absolute URL.
  • Test every important page in X's Card Validator before posting.

Frequently asked questions

What is a Twitter Card?

A set of tags that turns a shared link on X into a rich preview with an image, title, and description, instead of a plain text link.

Do I need Twitter Card tags if I have Open Graph tags?

X falls back to Open Graph tags, but setting Twitter tags explicitly gives you control and makes testing easier.

Why is my Twitter Card not showing?

Common causes are a missing twitter:card tag, a relative or blocked image URL, or an image that is too small. Use the Card Validator to diagnose it.
