Meta Description Length: How Long Should It Be?

A meta description can be any length, but Google usually shows only 150 to 160 characters of it. A description that runs long is cut off mid-sentence, and the cut often lands on the words that were supposed to persuade the searcher to click. Length is therefore a practical skill, not a technical detail.

This guide explains the limits on desktop and mobile, how to write a description that fits, and what to do when the important information will not fit.

The limits on desktop and mobile

On desktop, Google shows about 150 to 160 characters of a meta description. On mobile, the limit is roughly 120 characters, because the screen is narrower. A description written for desktop may be cut short on a phone, which is where most searches now happen.

The safe target is 120 to 160 characters. A description in that range displays fully on desktop and mostly on mobile, with only the last few words at risk. If the description is shorter than 120 characters, it may display fully everywhere, but it may also say too little to persuade anyone.

Why length matters for clicks

A description that is cut off mid-sentence looks unfinished, and searchers notice. They compare your result with the ones above and below it, and a clean, complete description signals a professional page. A truncated description signals a page that was not finished with care.

Length also affects how much you can say. A 160-character description has room for a benefit, a detail, and a call to action. A 90-character description has room for one of those. Use the space: a description that is too short wastes the only free advertising Google gives you.

Writing a description that fits

Write the description in one sentence of 120 to 160 characters. Start with the benefit or the answer, add one specific detail, and end with a call to action if it fits. Then count the characters with the Meta Description Checker on this site and trim ruthlessly: remove adjectives, shorten phrases, and cut any word that does not earn its place.

If the important information will not fit, prioritise. The benefit matters more than the feature list, and the call to action matters more than the company name. A searcher who wants the feature list will find it on the page; the description's job is to get them there.

When Google ignores your length

Google sometimes shows a longer snippet by pulling text from the page, especially when the searcher's query matches a specific passage. That is normal, and it is not a failure of your description. It means Google found a better answer to that particular query inside your content.

The reverse also happens: Google may show a shorter snippet, or a different one, for a query your description does not address. Write the description for the page's main topic, and let Google adapt it for specific queries. That is how the system is designed to work.

Key takeaways

  • Aim for 120-160 characters: full on desktop, mostly full on mobile.
  • Start with the benefit, add one detail, and end with a call to action if it fits.
  • Trim ruthlessly: cut any word that does not earn its place.
  • Google may show a different snippet for specific queries; that is normal.

Frequently asked questions

How long should a meta description be?

About 120 to 160 characters. Longer descriptions are cut off, and shorter ones may say too little to persuade a click.

Why is my description cut off on mobile?

Mobile shows about 120 characters. A description written for desktop may lose its ending on a phone.

Does Google always use my meta description?

No. Google may pull text from the page instead, especially when the query matches a specific passage. A good description is still used most of the time.
